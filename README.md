# Notenlerner

Android-App zum Lernen von Noten auf der Gitarre.

## Funktionen

- Notenlehrer mit Notendarstellung und Mikrofon-Erkennung
- Standard-Gitarrenstimmgeraet fuer E A D G B E
- Schwierigkeitsstufen fuer den Notenlehrer
- Platzhalter fuer Pentatonik und Fingeruebungen

## Entwicklung

```powershell
.\gradlew.bat testDebugUnitTest assembleDebug
```

Die App benoetigt Mikrofonzugriff fuer Pitch-Erkennung und Stimmgeraet.
